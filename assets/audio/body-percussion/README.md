# Campioni di body percussion

I campioni `mani`, `petto` e `cosce` derivano dal progetto open source
[`sfzinstruments/body_percussion`](https://github.com/sfzinstruments/body_percussion).

Licenza della fonte: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

Per l'uso sul sito i file originali sono stati convertiti in WAV mono, 16 bit,
22.050 Hz. Le due varianti per gesto vengono alternate durante la riproduzione.
